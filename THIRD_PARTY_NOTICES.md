## RaceMenu/SKEE BodyMorph interface

`src/third_party/skee/SKEE.h` contains the public RaceMenu/SKEE BodyMorph ABI
declarations, adapted from the interface header used by OBody NG:

https://github.com/Aietos/OBody-NG/blob/main/include/SKEE.h

The upstream RaceMenu interface is also published here:

https://github.com/expired6978/SKSE64Plugins/blob/master/skee64/IPluginInterface.h

complete text is retained in the root `LICENSE` file.

## SKSE Menu Framework 3 API

`src/third_party/skse_menu_framework/API.h` contains a minimal dynamic subset
adapted from QTR-Modding's public SKSE Menu Framework 3 API header:

https://github.com/QTR-Modding/SKSE-Menu-Framework-3-API

The upstream API header is licensed under the GNU Lesser General Public License
version 2.1. MPF resolves it dynamically, so the framework remains optional.
